视频识别 / 动作识别对抗攻防：2023–2026

面向视频识别、动作识别、骨架动作识别及视频 MoE 鲁棒性的可交互研究地图。重点覆盖 2023 年至 2026-10-18 的 arXiv 与公开会议/期刊页面；本版排除视频生成安全与 VideoLLM 内容审核，专注识别模型对抗攻击、防御与训练。

先读结论：研究范式正在发生什么变化？

2023–2024：核心问题仍是“视频太高维”，所以攻击研究集中在关键帧、关键区域、稀疏扰动和查询效率；防御开始从图像方法迁移到视频的时空结构，例如压缩感知、检测和局部补丁移除。

2025–2026：对抗研究一方面继续优化跨模型迁移、时空稀疏和频域黑盒攻击，另一方面开始研究快速对抗训练、骨架动作识别迁移攻击，以及视频 MoE 路由器与专家模块的组件级鲁棒性。

2026：最重要的新方向是 observation-level / pipeline-level attack：攻击者不必让每个已观察像素“对抗”，只要让模型看不到、压掉或忽略关键安全信号即可。DefTEval 进一步表明，传统输入净化与这种系统级威胁存在明显的层级错配。

类别机制代表
A1 梯度 / 像素扰动对全帧或部分帧优化连续扰动；重点核对白盒权限、扰动预算与时序一致性。DeepSAVA、SVASTIN、FeatureFool
A2 决策型黑盒与查询攻击目标模型只返回标签或有限反馈；核心成本是 query budget。AstFocus、STDE patch attack、Decision-based Sparse Attack、SLA
A3 时空稀疏 / 补丁攻击只修改少量像素、局部补丁或关键帧，降低扰动面积和搜索空间。STDE、SS-CMT、DSAA、RLVS
A4 跨模型 / 跨模态迁移在替代模型（包括图像模型）生成扰动，迁移到未知视频识别模型。I2V TPAMI、SS-CMT、DSAA、BMTC、Transformer transfer
A5 骨架动作识别攻击攻击对象是关节坐标与运动序列，而非 RGB 像素。Hard No-Box SMI、TASAR
A6 后门 / 数据投毒（独立威胁）训练阶段埋入触发器，测试时触发目标标签；与测试时 evasion attack 分开统计。Temporal-Distributed Backdoor、Look, Listen, and Attack
A7 架构组件级攻击攻击 MoE 路由器与专家之间的协同决策，而非只攻击最终分类头。Video MoE TLGA / J-TLGA

科学分类：防御方法

类别机制代表
D1 对抗训练将对抗样本或攻击分布纳入训练，提升模型内生鲁棒性。DeepSAVA、BEAT、VFAT-WS、J-TLAT
D2 快速 / 频域对抗训练用低成本内层攻击、频率增强与时空一致性降低训练成本。VFAT-WS
D3 骨架运动分布建模显式利用骨架自然运动流形与贝叶斯建模防御攻击。BEAT
D4 输入变换 / 时序随机化推理时改变输入时序以破坏攻击结构；必须同时评估干净精度。Temporal Shuffling
D5 压缩、重建与净化通过压缩域、重建或生成式净化削弱扰动，并测试自适应攻击。SECVID、VideoPure、FMVP
D6 检测与拒识判断输入是否为对抗样本，再拒绝、复核或触发净化。Multimodal Attack Detection
D7 补丁检测与移除定位局部高风险纹理并遮蔽或替换。PatchZero
D8 组件级鲁棒训练分别强化路由器、脆弱专家，再联合训练整个视频 MoE。J-TLAT

研究空白与值得继续追的方向

  1. 自适应攻击下的真实鲁棒性：很多净化器在非自适应攻击上很好，但攻击者一旦把防御本身纳入优化，结论可能改变。
  2. 视频编码链路：H.264/H.265/AV1、转码、缩放、帧率变化会同时摧毁攻击与防御；“社交平台上传后还能否成立”应成为标准实验。
  3. 模型架构与训练机制：2026 的证据表明只做 pixel purification 不够，需要从 sampling coverage、局部 token 保留、视觉-语言融合权重到安全解码全链路设计。
  4. 物理世界与实时流：摄像头、运动模糊、曝光、网络丢帧、在线延迟仍明显欠研究。
  5. 统一 benchmark：识别攻击、骨架攻击、迁移攻击与后门攻击 目前指标割裂，缺少统一 threat model 和跨任务 robustness score。
  6. 语义型扰动：从“不可见噪声”转向自然 Logo、PiP、多片段、视觉提示、时间组合，意味着未来防御必须理解语义与因果，而不只是去噪。
