AdvFM

AdvFM: Lookahead Flow-Matching Velocity-Field Attacks for Imperceptible and Transferable Adversarial Examples · Runze Liu et al.

摘要中文要义 （基于原摘要概述，非逐字翻译）

现有生成式 unrestricted adversarial attacks 往往直接在图像空间优化，或依赖 diffusion 的去噪—再加噪过程，因此在跨模型迁移和对抗防御方面受到限制。AdvFM 转而在 Flow Matching 的连续时间速度场中注入对抗信号：在噪声状态 xt 上先预测终点重建，再对重建结果施加 PGD 扰动，并将该扰动转化为速度场变化，从而放大噪声空间中的攻击更新。进一步的 lookahead 版本联合优化当前重建与前推后的重建，降低 ODE 轨迹上的时间错配。理论分析强调 step amplification、Gaussian smoothing 带来的低梯度方差/更强 surrogate-target alignment，以及更偏向 robust-tangent directions 的扰动；实验表明其黑盒迁移和抗净化/抗对抗训练能力均具有竞争力。

研究动机：为什么从 Diffusion 转向 Flow Matching？

01随机性导致梯度噪声

Diffusion 每步 re-noising，使 surrogate update direction 波动更大，削弱与跨模型共享梯度方向的对齐。

02对抗信号反复收缩

时间相关噪声不断重新加权 reconstruction 与 noise，携带攻击信息的分量难以稳定积累。

03净化容易去掉法向扰动

作者认为 ODE flow 更容易让扰动沿数据流形切向传播，因此对 purification 与 robust models 更有存活能力。

核心贡献

① Velocity-Field Attack

把攻击从 pixel perturbation 提升到连续时间 velocity field：对终点 reconstruction 的 PGD 更新被转换成当前时间的 velocity perturbation。

② Lookahead Two-Point Objective

同时考虑“当前 reconstruction”和“向前 rollout 后 reconstruction”，修正只攻击当前点带来的 temporal mismatch。

③ 理论解释 Transferability

从 step amplification、Gaussian smoothing / gradient variance、surrogate-target alignment、robust-tangent directions 等角度解释为何更易迁移。

④ 强黑盒与抗防御实验

覆盖 CNN/Transformer target，并攻击 purification defenses 与 adversarially trained models。

方法详解

Step A · 在 Flow Matching 轨迹中得到噪声状态

Flow Matching 学习连续速度场 vθ(x,t)，通过 ODE 将简单噪声分布连续 transport 到数据分布。AdvFM 不重新训练该生成模型，而把它冻结，利用其连续轨迹作为攻击载体。

dx/dt = vθ(x,t)

Step B · 对终点 reconstruction 做内层 PGD

给定当前状态 xt，估计对应的 t=1 reconstruction，在该 reconstruction 上优化分类损失，得到 δ。关键不在于直接输出 x+δ，而是把 δ 转换成 velocity-field modification。

→
reconstruct x₁ᵗ
→

→
ODE update

Step C · Lookahead：攻击“现在 + 下一步”

L_LA(δ;t) = w · L_f(x₁ᵗ + δ,y) + (1−w) · L_f(x₁^(t+Δt)(δ),y)

当 w=1 时退化为不带 lookahead 的版本。论文实验使用 w=0.3。直觉上，第一项保证当前攻击性，第二项要求该对抗方向经过 flow rollout 后仍然有效，因此更关注“可传播”的攻击信号。

Step D · 为什么可能更迁移？

Flow smoothing → gradient variance ↓ → surrogate-target alignment ↑ → black-box transfer ↑
tangent-like perturbation ↑ → purification survival ↑ / robust-model alignment ↑

关键实验发现

1
跨模型迁移明显增强。

平均黑盒 ASR：VGG19 source 为 70.35%，RN50 为 72.05%；相较此前强基线 APA 分别提升约 4.49 和 7.64 个百分点。Swin-B source 达 64.88%，领先 APA 约 3.39 点；ViT-B/16 source 为 68.22%，略低于 APA 的 69.73%。

2
Lookahead 对黑盒迁移比对白盒更重要。

以 RN50 为 surrogate，完整 AdvFM 的黑盒平均 ASR 约 72.05%，去掉 lookahead 后约 64.31%；说明 two-point objective 主要改善的是可迁移方向，而非单纯强化 white-box optimization。

3
抗净化/抗鲁棒模型能力是亮点。

论文报告在 NRP、randomized smoothing 以及多种 adversarially trained CNN/ViT 上取得很强 ASR；DiffPure 上则并非全面领先，说明“切向扰动更抗净化”的优势并不是对所有 purification 都绝对成立。

FMVP

FMVP: Masked Flow Matching for Adversarial Video Purification · Duoxun Tang et al.

摘要中文要义 （基于原摘要概述，非逐字翻译）

视频识别模型容易受到对抗攻击，而 diffusion purification 往往存在采样效率低、生成轨迹弯曲等问题。直接把 adversarial video 回归为 clean video 又很难可靠去除细微但结构化的攻击模式。FMVP 的核心做法是：先通过 masking “物理打碎”全局 adversarial structure，再利用带 inpainting objective 的 Conditional Flow Matching 重建干净视频动态；同时加入 Frequency-Gated Loss，抑制高频 adversarial residual、保持低频语义结构。作者进一步设计 Attack-Aware 与 Generalist 两种训练范式，并在 UCF-101 / HMDB-51、标准攻击和 adaptive DiffHammer 下验证鲁棒性，同时发现模型的 flow/净化信号还能用于 zero-shot adversarial detection。

研究动机：为什么“先打碎，再重建”？

01Diffusion purification 慢

反复采样/去噪带来较高推理成本，而且轨迹更复杂；Flow Matching 的 ODE 路径更直接。

02直接 regression 不够

对抗扰动虽然视觉上很小，却可能形成跨帧、全局一致的攻击结构；直接学习 adv→clean 映射可能保留攻击模式。

03视频需要保语义动态

净化不能只“去噪”，还要恢复动作与时序结构，因此作者把任务设计成 masked video inpainting / dynamics reconstruction。

核心贡献

① Masked Adversarial Space

不是直接从 x_adv 开始净化，而是先 mask，主动破坏 adversarial pattern 的全局结构。

② Conditional Flow Matching Inpainting

学习从 masked adversarial state 到 clean video 的连续 transport，重建缺失内容与视频动态。

③ Frequency-Gated Loss

在频域中对速度场/目标流差异进行加权，更强调语义相关低频结构，并抑制高频对抗残差。

④ 两种训练范式 + 检测能力

Attack-Aware 针对已知攻击；Generalist 面向未知攻击。净化过程还提供 zero-shot adversarial detection 信号。

方法详解

Step A · Masking：先破坏 adversarial structure

FMVP 的核心观点是：细微扰动之所以难净化，不是因为幅值大，而是其结构对分类器高度有效。因此推理时先将 adversarial video 映射到 Masked Adversarial Space，破坏攻击模式的连续性，同时利用邻域/未遮挡内容保留可恢复语义。

Step B · Conditional Flow Matching：把净化改造成 transport

训练目标不是普通 frame-wise denoising，而是学习一个条件速度场，将 masked source distribution transport 到 clean-video target distribution。推理时使用 Euler 离散化沿 ODE 从 t=0 推到 t=1。

x_(k+1) = x_k + vθ(x_k,t_k) · Δt

Step C · Frequency-Gated Loss

作者认为 adversarial residual 往往更偏高频，而视频语义与主体结构需要更好保持，因此对频域误差施加门控权重。公开解读给出的训练形式为：

L_total = λ_CFM · L_CFM + λ_FGL · L_FGL

其中公开版本解读报告 λCFM=1、λFGL=0.2。FGL 的设计重点不是简单低通滤波，而是在训练 velocity field 时显式强化结构保真。

Step D · Attack-Aware vs Generalist

Attack-Aware

训练时接触特定攻击分布，例如 PGD/CW，追求已知威胁下更高的针对性恢复。

Generalist

不绑定某一种攻击，通过更通用的噪声/掩码构造学习恢复机制，以提升未知攻击泛化。

关键实验发现

1
标准攻击下鲁棒准确率很高。

作者在 UCF-101 与 HMDB-51 上报告：对 PGD 的 robust accuracy 超过 87%，对 CW 超过 89%，优于 DiffPure、DP、TS 与 FlowPure 等基线。

2
不仅防标准攻击，还测试 adaptive attack。

论文使用 DiffHammer 验证自适应威胁，说明评估不只停留在“攻击者不知道 purification”的弱威胁模型。

3
Masking + FGL 是互补关系。

Masking 从空间/时空结构上破坏攻击模式；FGL 从频率结构上约束重建，两者共同服务于“破坏 adversarial structure，同时保留 clean semantics”。

4
净化器还能变成 detector。

作者报告 zero-shot detection 的 AUC-ROC 约为 0.98 (PGD) 和 0.79 (CW)。CW 更不可感知，因此 clean / adversarial score distribution 重叠更多。

4. 对 Flow Matching × 对抗鲁棒性的 Research Takeaway

共同趋势：Flow Matching 不再只是生成模型训练范式，而开始成为 adversarial robustness 的“连续 transport substrate”。攻击侧利用 velocity field 的平滑与可传播性寻找更稳定的攻击方向；防御侧利用 conditional transport 把受攻击输入重新拉回干净视频动态。
AdvFM 给出的启示

“Flow improves attack”不能只解释为换了生成器；真正有价值的是：为什么 flow trajectory 会改变 gradient variance、cross-model alignment 与 tangent/normal geometry。

FMVP 给出的启示

“Flow improves defense”也不能只靠 reconstruction；关键是先改变 adversarial input distribution（masking），再通过 CFM 重建，并显式处理 frequency / video dynamics。
