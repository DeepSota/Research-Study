1. ICLR 2026 已经完成什么？

当前论文已经形成 Router → Expert → Overall MoE 的 component-wise attack/defense 主线，因此扩刊应当避免重复“谁更弱”这一层问题。

01
Attack

TLGA / J-TLGA

利用 temporal adaptive step-size 与 local Lipschitz sensitivity，分别攻击 Router、Expert、整体 MoE；J-TLGA 进一步利用 Router–Expert 协同脆弱性。

02
Defense

TLAT / J-TLAT

从 Router robustness、weak-expert robustness 到 overall MoE robustness 进行分层式 adversarial training。

03

Achilles' Heel

组件协同具有“双刃剑”效应：Router 与 Expert 的联合脆弱性会让 joint attack 显著强于整体式攻击。

04
Theory

MoE Lipschitz Upper Bound

TPAMI 需要把已有 Lipschitz 理论推进到 coupling 与 temporal propagation。

2. TPAMI 新科学问题

核心问题：为什么一个很小的输入扰动，不只是让某个 Router/Expert 变脆，而会改变整个视频的 expert-selection trajectory，并沿时间传播，最终导致系统性失效？
x₁:T → r₁,r₂,…,rT → e₁,e₂,…,eT → temporal expert path → prediction

研究对象从单点 routing result 升级为 Adversarial Routing Trajectory，从 weak expert 升级为 weak temporal expert path。

4. Innovation II — Routing Cascade / Failure Propagation

把 Video MoE 表示成 Temporal Expert Routing Graph，研究脆弱性如何沿 expert path 传播。

Gₜ=(V,Eₜ), V={E₁,…,EM}

V(π)=Σₜ v(Eᵢₜ)+λΣₜ c(Eᵢₜ,Eᵢₜ₊₁)

πclean → πvulnerable
叙事升级：ICLR 找到 weak expert；TPAMI 找到 weak adversarial path，并解释 routing perturbation 的 temporal cascade。

5. Innovation III — Expert Vulnerability Score (EVS)

把“最低 Router confidence ≈ weakest expert”升级为显式 vulnerability estimator。

Vᵢ(x)=α Lᵢˡⁱᵖ + β Mᵢ⁻¹ + γ Gᵢ + η Uᵢ

Local Sensitivity

局部 Lipschitz / finite-difference sensitivity。

Decision Margin

真实类别与最大错误类别之间的 margin。

Gradient & Uncertainty

gradient sensitivity、routing uncertainty、temporal consistency。

升级：Router → Lowest-Confidence Expert 变成 Router → Most-Vulnerable Expert / Path。

7. 新防御 A：Path-wise J-TLAT

从三级训练升级为 Router → Expert → Path → Overall MoE。

minθ maxδ [ Lcls + λ₁Lroute + λ₂Lexpert + λ₃Lpath + λ₄Lbalance ]

Path Consistency

Lpath-consistency = D(Pclean,Padv)

让 clean / adversarial 的 expert-transition dynamics 保持稳定。

Vulnerability Balancing

Lbalance = Var(V₁,…,VM)

避免少数“极弱专家”成为稳定攻击入口。

9. Theory — Router–Expert–Coupling–Temporal 分解

不重复 ICLR 的 Lipschitz upper bound，而是解释 joint vulnerability 为什么会被放大。

ΔF = Σᵢ ΔRᵢ Eᵢ + Σᵢ Rᵢ ΔEᵢ + Σᵢ ΔRᵢ ΔEᵢ
Routing　　Expert　　Coupling

再加入 temporal propagation：

||ΔF₁:T|| ≤ B_R + B_E + B_C + B_T

目标是给出 routing instability 沿时间累积/传播的 bound，并用 routing cascade 验证理论预测。
