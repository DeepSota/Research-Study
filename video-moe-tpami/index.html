2. 整篇 TPAMI 的核心故事

最核心 insight：Video MoE 的 Achilles' Heel 本质不是单独的 Router 或某个 Weak Expert，而是二者之间形成的 Vulnerable Routing Boundary。
Achilles' Heel = Small Routing Margin + High Router Sensitivity + Large Expert Robustness Gap

所以全文结构应当是：WHY → HOW FRAGILE → WHERE → HOW TO ATTACK → HOW TO FIX。

3. Contribution 1 — Routing Decision Geometry & Robustness Theory

Routing Margin

离最近 routing boundary 有多远？

M_R(X) = w_(K)(X) − w_(K+1)(X)

对任意 selected expert i 与 candidate expert j：

M_ij(X) = w_i(X) − w_j(X)
Minimum Perturbation

改变 routing 至少需要多大扰动？

ε*_R(X) = min_δ ||δ||_p
s.t. TopK(R(X+δ)) ≠ TopK(R(X))

4. Vulnerable Routing Margin：统一 Router 与 Weak Expert

不是所有 routing switch 都危险。真正危险的是 Robust Expert → Vulnerable Expert。

ΔV_ij = V_j − V_i
VRM_(i→j)(X) = M_ij(X) / ([ΔV_ij]_+ + ε)
VRM 越小：目标 Expert 越近、越弱、越容易通过较小 perturbation 到达，因此越危险。

5. Minimum Harmful Routing Perturbation

ε*_H(X) = min_δ ||δ||_p
s.t. ∃ j ∈ E_weak : j ∈ TopK(R(X+δ))

ε*R

Router 有多容易改变？

ε*H

Router 有多容易做出“危险改变”？

ε*H 比单纯 routing switch 更适合成为 TPAMI 主指标。

6. Routing Robustness Bound

|w_i(X+δ) − w_i(X)| ≤ L_i ||δ||_p
M_ij(X+δ) ≥ M_ij(X) − (L_i + L_j)||δ||_p
||δ||_p < M_ij(X)/(L_i+L_j) ⇒ j 无法超过 i
ρ_R(X) ≥ min_{i∈TopK, j∉TopK} M_ij(X)/(L_i+L_j)
ρ_H(X) ≥ min_{i∈TopK, j∈E_weak} M_ij(X)/(L_i+L_j)
理论主结论：Routing Robustness ≈ Routing Margin / Router Sensitivity；整体风险再由 Expert Robustness Gap 调制。

12. Contribution 4 — MART

Margin-Aware Robust Routing Training

理论反向指导 Defense

Margin ↑ + Sensitivity ↓ + Worst-Expert Robustness ↑

Harmful Routing Margin ↑

L_HRM = Σ_{j∈E_weak} V_j [m0 − (w_i−w_j)]_+

越脆弱的 expert，需要越大的安全距离。

Router Sensitivity ↓

L_RS = ||∇_X R(X)||

重点压低 vulnerability map 中最危险维度的 sensitivity。

Worst-Expert Robustness ↑

max_θ min_i ρ(E_i)

减少单个极弱 Expert 成为稳定攻击入口。

Harmful Routing Consistency

L_HRC = Σ_j V_j D(R_j(X),R_j(X+δ))

越弱的 expert，越不允许 adversarial routing 朝它漂移。

L_MART = L_clean + λ1L_adv + λ2L_HRM + λ3L_RS + λ4L_balance + λ5L_HRC
