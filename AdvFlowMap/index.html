1. WHY：为什么 Flow Transport 能帮助发现通用迁移方向？

传统局部攻击

\[g_s=\nabla_X\mathcal L(f_s(X),y)\]

攻击方向由 surrogate 的局部 decision landscape 决定，因此容易包含 architecture-specific 成分。

核心分解假设

\[g_s=g_{\mathrm{shared}}+g_{\mathrm{specific}}\]

shared 成分对应跨模型稳定语义方向；specific 成分更容易随模型或局部邻域改变。

Flow Stability Principle：若一个对抗方向对应自然视频流形上的共享脆弱性，它应在多个自然 Flow Transport 下保持稳定；surrogate-specific 的局部方向则更容易发生漂移。

核心假设： Flow Stability ↑ → Target Gradient Alignment ↑ → Black-box Transferability ↑

2. HOW TO EXPLORE：用 Flow Transport 探索自然视频流形

Flow Matching

瞬时速度

\[\frac{dX_t}{dt}=v(X_t,t)\]

描述当前时刻的 instantaneous velocity。

MeanFlow

有限区间平均速度

\[u(X_t,r,t)=\frac{1}{t-r}\int_r^t v(X_s,s)\,ds\]

从“单点速度”升级到 finite-interval transport。

Flow Map

Two-time Transport

\[\Phi_{r\rightarrow t}(X_r)=X_t\]

直接提供视频在自然流形上的有限时间 transport operator。

3. WHAT：哪些攻击方向是真正“共享”的？

对每条有限时间 transport trajectory，计算 transport 后的对抗方向：

\[g_k=J_{\Phi_k}(X)^{T}\nabla_{X_k}\mathcal L(f_s(X_k),y),\qquad X_k=\Phi_k(X)\]

High Transport Agreement

\(\cos(g_i,g_j)\) 高；方向在不同 flow interval 下稳定。

解释：更可能对应 transport-invariant / model-shared adversarial component。

Low Transport Agreement

\(\cos(g_i,g_j)\) 低；方向随 flow interval 显著变化。

解释：更可能是 surrogate-specific local noise。

关键思想：不是把多条梯度简单平均，而是寻找在自然 transport geometry 下保持一致的 adversarial direction。

4. 核心科学发现：Adversarial Flow Invariance

整篇论文最需要被实验支持的发现：

\[\boxed{\text{Flow Invariance}\ \longrightarrow\ \text{Model Invariance}\ \longrightarrow\ \text{Transferability}}\]

Adversarial Parallel Transport Consistency (APTC)

我们要求原始点上的攻击方向，经 Flow Map Jacobian transport 后，与到达新流形点后重新得到的攻击方向一致：

\[d(\Phi_k(X))\approx J_{\Phi_k}(X)d(X)\]
\[\mathcal L_{\mathrm{inv}}=\frac{1}{K}\sum_k\left[1-\cos\!\left(d(\Phi_k(X)),J_{\Phi_k}(X)d(X)\right)\right]\]
定义：若上述关系对多个 \(\Phi_k\) 都成立，则称 \(d\) 为 Flow-Invariant Adversarial Direction。这比 PCA/SVD 式的“梯度相似性”更直接刻画方向在视频流形上的 transport consistency。

5. VIDEO：Temporal Semantic Transport

图像级 flow invariance 还不够。视频攻击方向必须能够沿动作语义轨迹传播，而不是固定在 pixel coordinates。

Semantic Correspondence

从 frozen video / self-supervised encoder 提取跨帧 token：

\[A_{\tau\rightarrow\tau+1}=\operatorname{Softmax}\!\left(\frac{F^\tau F^{\tau+1T}}{\sqrt d}\right)\]

Temporal Transport

共享攻击方向沿 correspondence 传播：

\[d^{\tau+1}\approx A_{\tau\rightarrow\tau+1}^{T}d^\tau\]
\[\mathcal L_{\mathrm{temp}}=\sum_\tau\left[1-\cos\!\left(d^{\tau+1},A_{\tau\rightarrow\tau+1}^{T}d^\tau\right)\right]\]
Video-specific novelty：攻击方向不是“每帧独立有效”，而是能够沿动作语义 trajectory 被 transport，从而同时保持 temporal coherence 与 cross-model transferability。

6. MEASURE：Transferable Flow Score 与对抗流形

Flow Consensus \(C_F\)

不同 flow intervals 下方向的一致程度。

Flow Invariance \(I_F\)

APTC 所刻画的 parallel-transport consistency。

Temporal Transport \(T_F\)

攻击方向沿视频语义运动传播的一致程度。

\[\mathrm{TFS}(d)=\operatorname{Fuse}(C_F,I_F,T_F)\]

高 TFS 表示该方向在多个自然 Flow Transport 下稳定、在时间维度可传播，因此更可能属于跨模型共享的 transferable adversarial region。

Transferable Adversarial Flow Manifold

\[\mathcal M_{\mathrm{TA}}=\left\{X+\delta:\|\delta\|_p\le\epsilon,\;\mathcal I_F(\delta)\ge\gamma_F,\;\mathcal I_T(\delta)\ge\gamma_T\right\}\]

“Manifold”在论文中要谨慎表述：核心是由 flow-transport stability 与 temporal-transport stability 定义的 adversarial neighborhood，而不是把任意 gradient collection 直接称为 manifold。

12. CVPR Contribution：最终只写三个

1

Scientific Finding

揭示 flow-transport invariance 与 adversarial transferability 的联系：在自然视频 transport 下保持稳定的攻击方向，应具有更强的跨模型梯度对齐与黑盒迁移性。

2

AdvFlowMap

利用 finite-time Flow Transport 探索自然视频流形，并通过 Flow-Invariant Direction Mining 从 surrogate-specific local gradients 中提取更共享的攻击方向。

3

Temporal Semantic Transport

将共享攻击方向沿跨帧 semantic correspondence 传播，使攻击同时具有视频时序一致性与跨 architecture 迁移性。
